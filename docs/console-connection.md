# 控制台连接状态

视频传输和 `/api/status` SSE 是独立通路。已连通的 WebRTC、WebSocket 或
MJPEG 控制台不能仅因状态订阅异常显示“连接已中断”，也不能因此禁止浏览器截图。
视频传输自身失败、MJPEG 播放错误仍触发中断提示；无 HDMI 信号和协议回退沿用
各自的提示。连接恢复后，中断提示根据当前状态自动消失。

WebRTC Trickle ICE 候选交换可能在媒体已连通后失败；此时保留当前媒体连接。
媒体未连通时，候选交换失败仍按连接失败处理。真实 PeerConnection 失败及
持续断线继续由连接事件、断线宽限计时器和建连超时判断。

SSE 断线、完整快照无效、增量解析失败或缺少增量基准时，关闭旧订阅，延迟一秒
重新订阅并接收完整快照，随后再应用该连接的增量。忽略旧订阅的迟到事件；最后
一个消费者退出时取消重试。手动“重新连接”同时重建状态订阅和视频连接。

回归入口为 `pnpm test:transport-reconnect`，覆盖状态订阅恢复、连接恢复后的
弹窗、过期事件隔离、迟到的 ICE 错误，以及真实传输失败仍然可见的情形。
