# SE98 icons

Unmodified PNG assets from [nestoris/Win98SE](https://github.com/nestoris/Win98SE),
revision `2bab6e96cfcd76a55ee29fd3060460338adb8beb`. The upstream icon theme is by nestoris and contributors,
based on Grassmunk's Chicago95, with Faenza assets also credited upstream.

The upstream repository distributes this collection under the GNU General
Public License version 2; the complete upstream license accompanies these assets
in LICENSE. The PNG files are the original source format and are included here
without image edits, with local filenames changed only for packaging.

sources.json records each original path, resolved symlink target, and SHA-256.
Upstream source: https://github.com/nestoris/Win98SE/tree/2bab6e96cfcd76a55ee29fd3060460338adb8beb
